# Расширение "Этапы производства" — кнопка "Перемещение (материалы для раскроя)"

Изменения реализованы полностью в расширении `ЭтапыПроизводства` (префикс имён `Орто_`),
без изменения объектов основной конфигурации.

## Что делает кнопка

В форме списка документов "Заказ на производство", в разделе команд
"Создать на основании", появляется кнопка **"Перемещение (материалы для раскроя)"**.
Пользователь выделяет несколько заказов на производство и нажимает её.

Расширение:
1. Отбирает из табличной части "Запасы" выбранных заказов только строки, у которых
   `Этап.Наименование = "Раскрой деталей"`.
2. Сворачивает отобранные строки по Номенклатура + Характеристика + Партия +
   ЕдиницаИзмерения, суммируя Количество.
3. Открывает **новый (незаписанный) документ "Перемещение запасов"**, табличная часть
   "Запасы" которого заполнена свёрнутыми материалами.
4. В поле "Комментарий" перечисляет через запятую номера исходных заказов на
   производство.
5. Если все выбранные заказы на производство созданы на основании одного и того же
   документа "Заказ покупателя" (реквизит шапки `ЗаказНаПроизводство.ЗаказПокупателя`),
   то этот документ подставляется в поле "Основание" (`ПеремещениеЗапасов.ДокументОснование`).

Документ не проводится и не записывается автоматически — пользователь проверяет
и дозаполняет обязательные поля (склад-отправитель/получатель и т.д.) и сохраняет сам,
как и при обычном создании на основании.

## Код

- `CommonModules/Орто_ПеремещениеРаскройСервер/Module.bsl` — серверная логика отбора,
  свёртки и подготовки структуры `ЗначенияЗаполнения`.
- `Documents/ЗаказНаПроизводство/Commands/Орто_ПеремещениеРаскрой/CommandModule.bsl` —
  клиентский модуль команды, вызывает серверный модуль и открывает форму документа
  "Перемещение запасов" с параметром `ЗначенияЗаполнения` (стандартный платформенный
  механизм заполнения нового объекта, включая табличные части).

Оба файла уже содержат полный код — их нужно скопировать в тела соответствующих
модулей после создания объектов метаданных ниже.

## Что нужно создать в Конфигураторе (в расширении "ЭтапыПроизводства")

### 1. Общий модуль

`Общие модули.Орто_ПеремещениеРаскройСервер`

| Свойство | Значение |
|---|---|
| Имя | `Орто_ПеремещениеРаскройСервер` |
| Сервер | Истина |
| Вызов сервера (ВызовСервера) | Истина |
| Клиент (управляемое приложение) | Ложь |
| Клиент (обычное приложение) | Ложь |
| Внешнее соединение | Ложь |
| Привилегированный режим | Ложь |
| Повторное использование возвращаемых значений | Не использовать |

Текст модуля — из `CommonModules/Орто_ПеремещениеРаскройСервер/Module.bsl`.

### 2. Команда документа "Заказ на производство"

`Документы.ЗаказНаПроизводство.Команды.Орто_ПеремещениеРаскрой`

(Заказ на производство уже заимствован в расширении — команда добавляется как
собственный дочерний объект заимствованного документа, аналогично уже существующей
в конфигурации команде `ЗаказНаПроизводство.Команды.ЧастичныйВыпуск`.)

| Свойство | Значение |
|---|---|
| Имя | `Орто_ПеремещениеРаскрой` |
| Синоним | `Перемещение (материалы для раскроя)` |
| Группа | `КоманднаяПанельФормыСоздатьНаОсновании` |
| Тип параметра команды | `ДокументСсылка.ЗаказНаПроизводство` |
| Режим использования параметра | `Множественный` |
| Изменяет данные | Ложь |
| Отображение | Авто |

Именно группа `КоманднаяПанельФормыСоздатьНаОсновании` — это тот же служебный
идентификатор, которым в самой конфигурации УНФ помечена, например, команда
`ЧастичныйВыпуск`, и он автоматически размещает команду в выпадающей кнопке
"Создать на основании" как в форме документа, так и в форме списка — никаких
дополнительных правок формы списка не требуется.

Текст модуля команды (CommandModule) — из
`Documents/ЗаказНаПроизводство/Commands/Орто_ПеремещениеРаскрой/CommandModule.bsl`.

## Проверка

1. Открыть список "Заказы на производство".
2. Выделить несколько заказов, у части табличной части "Запасы" которых есть строки
   с этапом "Раскрой деталей".
3. "Создать на основании" → "Перемещение (материалы для раскроя)".
4. Убедиться, что открылся новый документ "Перемещение запасов": в "Запасы" — только
   материалы этапа "Раскрой деталей", свёрнутые и просуммированные; в "Комментарии" —
   номера заказов через запятую; в "Основании" — заказ покупателя (если он один на все
   выбранные заказы).
